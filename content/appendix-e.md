## 六、可以填写的投资备忘录

### 最初记录

- **一句话主张：** 我为什么研究这门生意？
- **支持证据：** 哪份材料、哪一天、哪一项可核对事实？
- **最强反证：** 什么已经与主张冲突？还缺什么？
- **关键假设：** 哪些未来条件尚未验证？
- **估值与价格：** 同日情景范围、报价、缓冲及主要误差来源。
- **当前行动：** 调查／观察／买入／持有／减仓／卖出；理由。
- **证伪条件：** 可观察事实、允许范围、时间窗口与对应动作。
- **下次复核：** 日期或事件，谁提供什么材料？

### 更新记录

| 日期／事件 | 新证据及来源 | 原判断是否改变 | 模型改了哪项、为什么 | 行动与执行情况 | 下次复核 |
|---|---|---|---|---|---|
| | | | | | |

### 青禾写好的短例

**日期与对象：** 2031年3月31日，青禾约30元报价；教学比较沿用2030年末估值，未计算三个月滚动。

**主张与证据：** 公司已扩大到140家系统门店，收入5,600万元；后期新增资本回报下降，2029、2030批次成熟结果仍待验证。2030年FCFF−5.2万元，现金余额含外部融资贡献。

**假设与反证：** 基准假设后续利润继续增长，但新增回报逐步下降。若成熟回报比预计更差、现金改善依赖少做必要投入，或管理层拒绝收缩低回报扩张，需下调路径。

**价值与行动：** 三情景20.53／35.02／61.51元；30元虽低于基准，仍高于悲观，继续观察，没有成交。

**下一次复核：** 取得后期批次成熟数据、现金桥与资本配置说明后重算；具体日期不编造。第11章条件性持仓的建仓日期与滚动价值，必须另填，不能用这份未成交备忘录替代。

## 七、复盘时把三件事分开

判断是否合理，要看当时证据和假设；执行是否合格，要看是否遵守自己写下的条件；结果如何，则记录真实现金、价格与期间。结果不能删除前两项。赚钱可能含运气，亏损也不自动证明每一步都错。

把旧版本留下来。多年后最有用的资料，往往不是一张不断被修饰的“正确答案”，而是你在不确定时究竟相信了什么、后来又为什么改变。
