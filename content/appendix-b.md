# 附录B：核心指标与口径速查表

> [!warning] 内容持续修订中
> 本站公开的是可完整阅读的修订稿，概念、案例与数据表达仍会继续校订。


遇到缩写时回来查，不必从第一行背到最后。金额先注明币种与单位，利润和现金流写明期间，资产负债与股数写明时点；比较两家公司前，先统一范围。以下是本书教学口径，真实报表还应查会计政策和附注。

## 从卖出一杯，到留下利润

| 指标 | 定义与公式 | 单位、期间及边界 | 正文入口 |
|---|---|---|---|
| 收入 | 公司提供商品或服务确认的金额 | 元／万元，某期间；不是银行到账，也不是加盟终端GMV | [第1章](./chapter-01) |
| GMV | 平台或系统成交总额，定义按披露核对 | 元，某期间；不能直接并入经营公司的收入 | 第1章 |
| 毛利润／毛利率 | 收入−直接成本；毛利润÷收入 | 金额／百分比，同期；成本分类影响可比性 | 第1章 |
| EBIT／营业利润率 | 本书为收入−原料成本−现金经营费用−折旧；EBIT÷收入 | 金额／百分比，同期；真实报表须核查营业利润范围 | 第1章 |
| 净利润 | 经营结果再处理利息、税及其他项目后归属的利润 | 金额，同期；并不全可分给股东 | 第1章 |
| 正常化利润 | 报告或口头起点加减有证据的经济调整 | 金额；与报告利润分列，每项调整留痕 | 第1章 |
| NOPAT | EBIT×（1−经营税率），税后经营利润 | 金额，同期；未扣融资利息，异常税率不可直接永续 | [第3章](./chapter-03) |

青禾2024年正文净利润按9.1万元展示；税率20%的模型精算为`（12−0.6）×80%=9.12万元`。这是展示取整差异，不能拿两位小数的模型与一位小数的正文强行逐分相等。

## 利润到现金：五个名称不要混用

| 名称 | 本书计算或含义 | 使用条件与边界 | 入口 |
|---|---|---|---|
| CFO，经营活动现金流 | 会计报表中经营活动的现金净流量 | 金额，某期间；利息分类依准则、政策核对 | [第2章](./chapter-02) |
| 正常化经营现金流代理值 | 青禾2024：9.1＋3−4=8.1 | 经济分析值；历史报告CFO未知，不是该年实际现金表 | 第2章 |
| FCF代理值 | 同口径CFO或明确标注的经营现金代理值−总Capex | 快速体检，未必覆盖并购等全部投入；不是通用的FCFF | 第2章 |
| 正常化所有者现金 | 青禾单店：9.1＋3−1−4=7.1 | 维持既有能力，1是维持性营运资本增加、4是维护Capex；已含利息影响 | 第2章 |
| FCFF | NOPAT＋折旧摊销−Capex−Δ经营NWC | 留给债权人和股东的现金；配WACC；并购与租赁须一致处理 | [第10章](./chapter-10) |
| FCFE | 净利润＋非现金调整−Capex−Δ经营NWC＋净借款 | 普通股股东层面，配股权成本；本书亦用CFO−Capex＋净借款 | 第10章 |

同样写“自由现金流”，归属和范围可能不同。读者应能在每次引用后补上“属于谁、扣了什么、哪一年、什么单位”。

## 存量、投入与回报

| 指标 | 定义／公式 | 时点、期间与适用条件 | 入口 |
|---|---|---|---|
| 经营净营运资本NWC | 应收＋存货＋经营预付−应付−客户预收 | 期末金额；本书不含现金和有息债务，真实公司按业务调整 | 第2章 |
| ΔNWC | 本期期末NWC−上期期末NWC | 期间变化；增加通常占现金，减少不一定可持续 | 第2章 |
| Capex | 固定资产等长期经营投入 | 期间现金支出；维持与增长需分析，分类不能重复 | 第2章 |
| 净再投资 | Capex−折旧摊销＋ΔNWC | 期间金额；公司DCF汇总口径，不是每家新店的55万元 | 第10章 |
| 投入资本 | 本书经营资产扣无息经营负债并排除超额现金 | 某时点金额；历史回报常用期间平均资本，商誉处理需交代 | 第3章 |
| ROE | 净利润÷平均股东权益 | 年度百分比；负权益或极小分母会失去直观意义 | 第3章 |
| 历史ROIC | NOPAT÷平均投入资本 | 同一经营范围与期间；高历史值不保证下一笔投入回报 | 第3章 |
| 批次成熟增量ROIC | 同一批次成熟年NOPAT÷对应新增资本 | 本书单店55万元；2029、2030成熟值仍是预测 | [第4章](./chapter-04) |
| 前向净再投资I_t | （NOPAT_(t+1)−NOPAT_t）÷ROIC_(t+1) | 年末投入支持下一年增量；首年NOPAT为独立输入 | 第10章 |
| 稳定期再投资率 | g÷稳定增量ROIC | 长期增长与回报一致，不能让增长免费发生 | 第10章 |

青禾2024历史ROIC为`9.6÷48=20%`；ROE按正文的取整数字计算，`9.1÷44.55≈20.43%`，保留一位小数为20.4%。不要把不同精度的分子、分母混着比较。批次回报则用单店成熟NOPAT除55万元，不把全公司利润增加直接归给当年新店。

## 价格、债务与风险

| 指标 | 公式或问题 | 适用条件与边界 | 入口 |
|---|---|---|---|
| 需求价格弹性 | 数量变化百分比÷价格变化百分比 | 同产品、可比期间的简化；不能排除竞争、天气等混杂因素 | [第6章](./chapter-06) |
| 成本传导 | 同销量下新增收入与新增成本金额比较，再看销量变化 | 两个百分比若分母不同，不能直接比大小 | 第6章 |
| 利息保障倍数 | EBIT÷利息费用 | 同期倍数，不能代替本金到期和现金日历 | [第7章](./chapter-07) |
| 可动用现金 | 账上现金−受限款−最低运营储备 | 时点金额；储备多少需按压力核查 | 第7章 |
| 资金缺口 | max（0，−逐期可动用余额） | 余额=期初可动用现金＋流入−流出；年度净流出不是缺口 | 第7章 |
| 股权稀释 | 原有股份在扩大后总股数中的比例下降 | 看新增资金创造的价值，比例下降不自动等于价值毁损 | [第8章](./chapter-08) |
| 净回购 | 实际回购扣除同期新增发行，分别核对金额与股数 | 授权≠执行；高价回购可能损害留下者 | 第8章 |

“广义股东收益率”有时把分红、净回购与净偿债相加并除以同口径股权市场价值，但各来源口径并不统一。它只是历史资金动作的统计，不能当预期投资回报；本书不据此给青禾打分。

## 价值与分母

| 指标 | 公式 | 单位与边界 | 入口 |
|---|---|---|---|
| 市值 | 同日股价×期末股数 | 金额，是市场报价 | [第9章](./chapter-09) |
| 会计EPS | 归属普通股利润÷期间加权股数 | 元／股，某报告期；稀释EPS另核查潜在股份 | 第9章 |
| 期末调整利润／股 | 同期利润÷期末完全摊薄股数 | 不是会计EPS；青禾为1.904元 | 第9章 |
| PE | 股价÷对应EPS，或市值÷配对利润 | 倍数；股本变化时两个表达需统一分母，亏损时不适合机械比较 | 第9章 |
| PS | 市值÷同期收入 | 倍数；不反映利润率、债务与资本需求 | 第9章 |
| EV／EBITDA | 企业报价÷同期息税折旧摊销前利润 | 倍数；EBITDA并非可分配现金 | 第9章 |
| 企业／股权FCF Yield | FCFF÷EV；FCFE÷股权价值 | 年现金／时点价值；负值不是损失率承诺 | 第9章 |
| 股权成本 | 普通股资金要求的回报 | 年百分比，配FCFE；不是经营ROIC | 第10章 |
| WACC | 股债权重综合的资本成本 | 年百分比，配FCFF；债务税盾及融资结构须一致 | 第10章 |
| DCF企业价值 | 显式期FCFF现值＋终值现值 | 估值日金额；是预测输出，与市场EV分开 | 第10章 |
| 普通股股权价值 | EV−债务及其他优先索取＋超额现金等非经营资产 | 同日金额；只计一次并统一租赁处理 | 第10章 |
| 每股价值 | 普通股股权价值÷同日完全摊薄股数 | 元／股；万元÷万股也得元／股 | 第10章 |

安全边际是价值判断与支付价格间用于抵御错误的缓冲，没有一档百分比适合所有公司。证据越弱、情景越宽，越不能靠一个好看的“折价率”宣布安全。卖出则回到新证据、滚动价值与组合约束，见[第11章](./chapter-11)。
